# 视频重制工坊

这是从原方案仓库整理出的开发起点，保留可运行静态原型和必要产品资料，剔除了飞书导出、验证截图、归档版本、临时文件和文档生成脚本。

## 目录

```text
src/
  index.html
  styles.css
  app.js
docs/
  product-plan-v3.16.md
  technical-terms.md
```

## 本地预览

直接打开：

```text
src/index.html
```

或启动本地静态服务：

```powershell
npm run dev
```

默认地址：

```text
http://localhost:5173
```
