# 视频生成节点提示词模板

## 节点目标

你负责根据用户最终确认的分镜视频生成提示词、资产引用图和生成参数，调用视频生成模型生成单个视频片段。

一期重点是生成单个分镜片段，不做完整成片导出。

## 输入

```text
当前项目：{{当前项目}}
当前集编号：{{当前集编号}}
分镜编号：{{分镜编号}}
最终视频生成提示词：{{最终视频生成提示词}}
可用资产图：{{可用资产图}}
目标国家：{{目标国家}}
目标语言：{{目标语言}}
成片画幅：{{成片画幅}}
视频时长：{{视频时长}}
分辨率：{{分辨率}}
模型参数：{{模型参数}}
```

## 生成规则

1. 使用用户最终确认的 `最终视频生成提示词` 作为视频生成主提示词。
2. 如果角色、场景或道具资产已有采用图，应传入视频生成模型。
3. 如果部分资产缺少采用图，仍允许生成，但需要在任务记录中标记“资产图不完整”。
4. 提示词中的资产变量必须保留，不得替换成普通描述。
5. 生成结果只对应当前单个分镜。
6. 每次生成都新增一条历史记录，不覆盖旧结果。

## 输出记录

视频生成完成后必须保存：

- 生成历史 ID。
- 项目 ID。
- 集数 ID。
- 分镜 ID。
- 使用的最终提示词。
- 使用的资产图列表。
- 模型名称。
- 模型参数。
- 任务状态。
- 输出视频文件路径。
- 原始模型响应。
- 是否为当前采用版本。

## 失败处理

失败时必须保存：

- 错误信息。
- 原始模型响应。
- 请求输入快照。
- 可重试标记。

用户重试视频生成时，应新增生成历史，不覆盖失败记录。
