# 视频重制工坊 MVP 开发方案

## 1. 一期目标

本项目一期目标是把当前静态原型升级为本地单机可跑通的 AIGC 短剧重制工作台。目标用户是 AIGC 短剧制作人员，核心不是做完整生产级平台，而是轻量跑通以下闭环：

```text
本地上传视频/文件夹
-> 本地保存项目和视频文件
-> 调用资产提取转化 Agent
-> 用户确认和编辑资产
-> 可选生成资产图
-> 调用分镜转化 Agent
-> 用户编辑分镜提示词
-> 调用视频生成模型
-> 生成单个视频片段
-> 查看生成历史、采用版本、下载片段
```

一期必须支持真实模型接口接入，同时保留 mock 模式，保证无 API Key 时也能开发和演示完整 UI、任务状态与数据流。

## 2. 一期非目标

- 不做多人协作、账号权限和线上部署。
- 不做生产级对象存储，视频、图片和结果文件先保存在本地。
- 不做后台视频项目真实 API 对接，只保留模拟链路。
- 不做自由拖拽式 Agent 工作流。
- 不强制要求所有资产都生成图片后才能进入分镜。
- 不做完整成片导出，一期只导出单个生成视频片段。

## 3. 技术栈

前端：

- React
- TypeScript
- Vite

后端：

- Python
- FastAPI
- SQLite
- 本地文件存储
- ffmpeg，用于视频元信息读取、封面截取、片段裁切和后续扩展

模型：

- 火山引擎豆包系列模型
- VLM / LLM / 文本生成 / 图片生成 / 视频生成都通过统一 provider 适配层调用

现有 `src/` 静态原型保留为视觉和流程参考，不继续在大 HTML / JS 文件中扩展真实业务逻辑。

## 5. 本地项目与集数规则

上传支持：

- 单个视频
- 文件夹批量视频
- 多集批量处理

文件夹上传时，集数排序规则：

```text
优先读取文件名中的最后一组数字
-> 自然排序
-> 无数字文件排在后面
-> 后续允许手动调整
```

示例：

```text
EP01.mp4
第01集.mp4
001.mp4
video_001.mp4
```

均识别为第 1 集。命名不需要一开始完全标准化，能识别 `001`、`01` 这类尾缀即可。

## 6. 功能模块清单

### 6.1 项目管理模块

- 创建本地项目
- 查看项目列表
- 查看项目处理状态
- 进入指定项目工作流
- 后台项目模拟入口

### 6.2 本地上传模块

- 单视频上传
- 文件夹上传
- 批量集数识别
- 上传后保存到 `data/projects/{projectId}/source/`
- 读取视频基础信息

### 6.3 视频文件管理模块

- 展示集数、文件名、时长、分辨率、处理状态
- 支持替换单集视频
- 支持删除本地集数
- 支持失败后重新处理

### 6.4 Agent 节点配置模块

一期使用配置文件，不做后台配置 UI。

配置内容包括：

- 节点名称
- 节点类型
- 模型名称
- system prompt 文件路径
- 输入组装规则
- 输出解析规则
- 模型参数
- mock / volcengine 模式切换

### 6.5 资产提取转化模块

调用统一资产提取转化 Agent，同时处理：

- 角色资产
- 场景资产
- 道具资产
- 资产本地化
- 资产出现片段索引
- 跨集历史资产库更新

### 6.6 资产确认模块

- 展示角色、场景、道具资产
- 支持编辑名称、描述、图像生成提示词、音色等字段
- 支持确认资产
- 未生成资产图时允许继续，但提示后续视频生成质量可能下降

### 6.7 资产图生成模块

- 支持用户编辑资产图提示词
- 支持重新生成
- 保存多次候选图
- 用户选择当前采用图

### 6.8 分镜解析生成模块

- 调用分镜转化 Agent
- 输入视频、资产库、资产出现片段索引、目标国家、目标语言、画幅
- 输出结构化分镜 JSON
- 同时生成可直接填入视频生成界面的完整提示词文本

### 6.9 分镜编辑模块

- 展示分镜列表
- 默认选中第一个可生成分镜
- 支持切换分镜
- 支持编辑最终视频生成提示词
- 一期不要求把编辑后的整段文本反向解析回结构化字段

### 6.10 视频生成模块

- 调用豆包视频生成模型
- 输入用户最终确认的完整提示词
- 传入可用资产图
- 支持任务轮询
- 保存生成结果

### 6.11 生成历史与采用版本模块

- 每次视频生成都新增一条历史记录
- 支持查看历史版本
- 支持选择采用版本
- 支持下载单个视频片段

### 6.12 后台项目模拟模块

- 首页保留“拉取后台视频项目”
- 展示模拟项目列表
- AI 剧模拟已有可复用资产资料
- 真人剧模拟普通分析链路
- 模拟项目仍然进入同一套本地项目、资产、分镜、视频生成流程

### 6.13 本地任务状态模块

任务状态至少包括：

```text
等待中
运行中
成功
失败
已取消
```

失败时保存：

- 错误信息
- 原始模型响应
- 当前输入快照
- 可重试节点

支持：

- 重试当前节点
- 从某个节点重跑后续链路

## 7. Agent 节点清单

### 7.1 资产提取转化 Agent

节点名称：

```text
asset_extraction_localization
```

职责：

- 完整读取当前集视频
- 结合历史资产库
- 识别角色、场景、道具
- 建立主资产与子资产关系
- 完成目标国家本地化
- 输出资产变量
- 输出资产出现片段索引
- 输出资产变更记录

处理顺序：

```text
第 1 集：输入空历史资产库，生成初始资产库
第 2 集：输入第 1 集后的历史资产库，更新资产库
第 3 集：继续更新
直到上传的所有集处理完成
```

### 7.2 资产图生成 Agent

节点名称：

```text
asset_image_generation
```

职责：

- 读取资产图生成提示词
- 叠加固定约束
- 调用图片生成模型
- 保存候选图

角色资产图固定约束：

```text
风格：真人写实风格
画质：模拟真实拍摄效果，8K超高清
光线：明亮柔和
构图：左侧正面胸像（正面面对镜头，目光看向镜头），右侧三视图（依次是正面、右侧面90°、背面），不允许出现第4个全身人物，不允许上下分两行或多行网格。
背景：干净的白色背景，无文字
人物肤感：皮肤质感真实自然，纹理清晰
姿态：自然直立站姿，双臂自然下垂贴于身体两侧，手指自然微曲，双脚平行与肩同宽
表情：角色默认微表情神态，嘴巴自然闭合，禁止夸张表情
道具：无。双手空握不持任何物品，腰间不挂载任何悬挂物，画面中无任何道具武器
约束：无水印，无文字，无logo，无畸形肢体，角色完整不裁切，脚下有自然投影
摄影强化：专业人像摄影、85mm镜头、浅景深、影棚布光、高分辨率、对焦清晰
光效建议：柔光、伦勃朗光、蝴蝶光、侧逆光
画质与质感要求：8K超清、极致细节、照片级真实
负面限制：避免卡通、绘画、3D渲染、模糊、畸形、低质量
```

场景资产图建议约束：

```text
真人写实风格，8K超高清，明亮柔和光线，目标国家本地化环境，完整展示空间结构，无人物，无水印，无文字，真实摄影质感。
```

道具资产图建议约束：

```text
真人写实风格，8K超高清，白色或自然背景，主体道具完整居中展示，无人物手持，无多余物体，无水印，无logo，真实材质细节。
```

### 7.3 分镜转化 Agent

节点名称：

```text
storyboard_prompt_generation
```

职责：

- 读取当前集视频
- 读取资产库
- 读取资产出现片段索引
- 按镜头变化和剧情分析共同切分分镜
- 每个分镜建议 8 至 15 秒
- 分镜时间段必须和资产出现时间对应
- 提示词中的资产引用不能乱引用
- 输出结构化分镜 JSON
- 为视频生成界面生成完整提示词文本

重要约束：

资产引用必须自然嵌入画面描述，而不是只在顶部罗列。示例：

```text
@张三在风雨交加的@办公大楼拿着一本@残破的笔记，神情压抑地走向门口。
```

后续接入 Doubao Seedance 2.0 时，需要根据官方接口确认资产引用的精确字段和语法。当前方案保留“资产变量自然嵌入提示词”的产品与数据结构约束。

### 7.4 视频生成 Agent

节点名称：

```text
video_generation
```

职责：

- 读取用户最终确认的视频生成提示词
- 读取可用资产图
- 调用视频生成模型
- 轮询任务状态
- 保存输出视频
- 写入生成历史

一期视频生成不强制传原视频关键帧，重点保证：

- 画面描述贴合原剧情
- 资产引用正确
- 资产出现时间和分镜时间一致
- 输出单个视频片段

## 8. 资产数据结构

### 8.1 统一资产库

资产提取转化 Agent 输出必须是合法 JSON。建议顶层结构：

```json
{
  "当前集编号": "",
  "目标国家": "",
  "目标语言": "",
  "资产库": {
    "角色资产": [],
    "场景资产": [],
    "道具资产": []
  },
  "资产出现片段索引": [],
  "当前集资产变更": {}
}
```

### 8.2 角色资产

角色使用主资产 + 子资产。

变量格式：

```text
{{角色_001_子资产_001}}
```

关键字段：

- 主资产编号
- 原剧角色名称
- 本地化角色名称
- 剧情身份
- 稳定人设定位
- 原剧核心形象描述
- 本地化核心形象描述
- 基础音色描述
- 目标语言声音要求
- 子资产
- 出现记录

### 8.3 场景资产

场景使用主资产 + 子资产。

变量格式：

```text
{{场景_001_子资产_001}}
```

示例：

```text
场景主资产：总裁办公室
子资产：总裁办公室-白天
子资产：总裁办公室-夜晚
子资产：总裁办公室-混乱状态
```

关键字段：

- 主资产编号
- 原剧场景名称
- 本地化场景名称
- 空间结构描述
- 本地化视觉描述
- 子资产
- 场景资产图生成提示词
- 出现记录

### 8.4 道具资产

道具不做子资产，保持轻量。

变量格式：

```text
{{道具_001}}
```

关键字段：

- 道具编号
- 资产变量
- 原剧道具名称
- 本地化道具名称
- 剧情功能
- 原剧视觉描述
- 本地化视觉描述
- 道具资产图生成提示词
- 出现记录

## 9. 分镜数据结构

分镜 Agent 输出 JSON，但前端必须能把结构化字段渲染成完整视频生成提示词文本。

建议结构：

```json
{
  "当前集编号": "",
  "目标国家": "",
  "目标语言": "",
  "分镜列表": [
    {
      "分镜编号": "分镜_001",
      "来源片段编号": "片段_001",
      "分镜时间范围": {
        "开始时间": "00:00:00",
        "结束时间": "00:00:10"
      },
      "引用资产变量": [
        "{{角色_001_子资产_001}}",
        "{{场景_001_子资产_001}}",
        "{{道具_001}}"
      ],
      "角色音色参考": "",
      "分镜场景设定": "",
      "分镜具体动作描述": "",
      "镜头列表": [
        {
          "镜头编号": "镜头1",
          "镜头描述": ""
        }
      ],
      "视频生成约束": "",
      "负面提示词": [],
      "最终视频生成提示词": ""
    }
  ]
}
```

`最终视频生成提示词` 是视频生成界面输入框的默认填充值。用户编辑后，保存为独立的 `editedPrompt`，不反向解析结构化 JSON。

拼接内容至少包括：

- 分镜时间范围
- 角色音色参考
- 分镜场景设定
- 分镜具体动作描述
- 镜头列表
- 视频生成约束
- 负面提示词

资产变量必须嵌入具体画面描述中，不能只在顶部机械列出。

## 10. 任务重跑规则

支持重试当前节点，也支持从某节点重跑后续链路。

建议规则：

- 重跑资产提取：后续资产确认、分镜和视频生成结果标记为过期或清空。
- 重跑资产图生成：只替换当前资产图片，不影响分镜。
- 重跑分镜生成：已有视频生成结果标记为过期，但不删除。
- 重跑视频生成：新增一条生成历史。

## 13. 模型模式

环境变量建议：

```text
MODEL_MODE=mock
VOLCENGINE_ACCESS_KEY_ID=
VOLCENGINE_SECRET_ACCESS_KEY=
VOLCENGINE_REGION=
DOUBAO_TEXT_MODEL=
DOUBAO_VLM_MODEL=
DOUBAO_IMAGE_MODEL=
DOUBAO_VIDEO_MODEL=
```

`MODEL_MODE=mock` 时：

- 不调用外部模型
- 返回固定 mock 资产、分镜和视频任务结果
- 用于 UI、任务流和数据结构开发

`MODEL_MODE=volcengine` 时：

- 调用真实火山引擎豆包模型
- 文件上传、任务轮询、错误处理按官方接口实现

## 15. MVP 开发顺序

建议按以下顺序推进：

1. 搭建 FastAPI + React + SQLite 基础工程。
2. 实现本地项目创建、单视频/文件夹上传、本地文件保存。
3. 实现任务系统、mock 模式、任务状态轮询。
4. 实现资产提取 mock 输出和资产确认页。
5. 接入配置文件读取 Agent prompt。
6. 实现分镜生成 mock 输出和分镜编辑页。
7. 实现视频生成 mock 流程、历史版本、下载入口。
8. 接入火山引擎文本/VLM 调用，跑通资产提取真实节点。
9. 接入分镜转化真实节点。
10. 接入图片生成真实节点。
11. 接入视频生成真实节点。
12. 补齐后台项目模拟链路。
13. 做端到端 Demo 验证。

## 16. 后续开发前必须补充的信息

开发真实模型调用前，需要补充：

- 火山引擎 API Key / Secret Key 或本地鉴权方式。
- 文本模型 ID。
- VLM / 视频理解模型 ID。
- 图片生成模型 ID。
- 视频生成模型 ID，尤其是 Doubao Seedance 2.0 接口。
- API endpoint、region、文件上传方式。

## 17. 验收标准

一期 Demo 验收以真实闭环为准：

1. 能上传一个或多个本地视频。
2. 能识别集数并保存到本地项目。
3. 能运行资产提取任务并展示角色、场景、道具资产。
4. 能编辑和确认资产。
5. 能可选生成资产图并选择采用图。
6. 能运行分镜生成任务。
7. 分镜提示词中资产变量嵌入正确，且时间段与资产出现时间对应。
8. 能把完整分镜提示词自动填入视频生成输入框。
9. 用户能编辑最终视频生成提示词。
10. 能调用视频生成并生成单个视频片段。
11. 能查看生成历史、选择采用版本并下载。
12. mock 模式和真实模型模式都能走通任务状态。
