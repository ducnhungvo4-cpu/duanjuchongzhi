# 技术说明与术语表

本文档用于补充 PRD 中刻意弱化的技术概念，供产品、算法和研发沟通时使用。

## 1. 术语对照

| 业务表达 | 技术/提示词表达 | 说明 |
|---|---|---|
| 全片资产库 | 分镜0 | 不是真实镜头，而是全片资产标准 |
| 资产映射表 | Asset Mapping | 原资产到目标资产的对应关系 |
| 目标资产库 | Target Asset Variable Library | 用 @变量 固定目标资产 |
| 视频片段节点 | Shot / Segment Node | 可独立用于 AI 视频生成的片段提示词 |
| 使用资产 | Asset References | 当前片段引用的 @变量 |
| 生成控制要求 | Generation Constraints | 对画幅、角色一致性、场景、字幕、水印的约束 |
| 生成规避项 | negative_prompt | 当前片段必须避免生成的问题 |
| 本地化资产重制 | Asset Remake / Localization | 按目标国家/地区重制人物、场景、道具等 |
| 英文成片文案 | Final English On-screen/Audio Text | 观众最终看到或听到的英文内容 |

## 2. 全片资产库规则

全片资产库必须先输出资产映射表，再输出目标资产库。

资产映射表只写对应关系：

```text
张飞 - Michel
中国县城街道 - Western Small Town Street
```

目标资产库只写目标资产：

```text
@Michel = Michel，35岁左右，欧美男性……
```

视频片段节点只允许调用目标资产变量，不允许再出现原资产名称。

## 3. 自动校验规则

系统至少需要校验：

1. 是否包含全片资产库；
2. 是否包含资产映射表；
3. 是否包含目标资产库；
4. 视频片段节点是否只使用目标资产；
5. 是否存在中文成片内容残留；
6. 是否存在原资产名残留；
7. 是否缺少时长；
8. 是否缺少生成控制要求；
9. 是否缺少生成规避项；
10. 是否出现目标国家资产混用。

## 4. 默认目标市场

用户未选择目标国家/地区时，默认使用：

```text
United States / Western English-speaking context
现代欧美现实主义短剧语境
```

只有用户明确要求“保留原国家，只做英文成片”时，才保留原视频国家视觉资产。
